## About
This is the github repo for my online portfolio. It is built using [svelte](https://svelte.dev/) and [vite](https://vitejs.dev/). It is hosted on [github pages](https://pages.github.com/). I used [github actions](https://github.com/features/actions) to build and deploy the site.

Hopefully I don't remake my portfolio soon.

I'm not a designer, but I tried to make the site look nice. I used [Nerd Fonts](https://www.nerdfonts.com/) for the icons and [Catppuccin](https://www.catppuccin.com/) for the themes.

## Development
### Prerequisites
- [node](https://nodejs.org/en/) (Tested with v20.18.1)
- [npm](https://www.npmjs.com/)
- [git](https://git-scm.com/)

To run the site locally, run the following commands:
```bash
git clone https://github.com/sopyb/sopyb.github.io.git # clone the repo
cd sopyb.github.io # go into the repo
npm install # install dependencies
npm run dev # vite will run the site on localhost:5173 by default
```
